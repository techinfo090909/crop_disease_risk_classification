# 🌱 Crop Disease Risk Classification

**Domain:** Agriculture &nbsp;·&nbsp; **Task:** Multi-class Classification &nbsp;·&nbsp; **Type:** Educational ML Prototype

A machine-learning system that classifies crop disease risk — **Low**, **Medium**, or **High** — from crop type, target disease, growth stage, and environmental readings (temperature, humidity, rainfall, leaf wetness, wind speed, soil moisture, and prior regional disease incidence). Built end-to-end: data validation → EDA → model training/comparison → deployment via an interactive Streamlit application.

> **Capstone Project** — Learn Depth Academy LLP, Track 1, Problem 16
> Free/open-source tools only. Educational prototype — not a production system or agronomic diagnostic tool.

## 📊 Dataset

| Property | Value |
|---|---|
| Rows | 10,000 |
| Features | 11 (3 categorical, 8 numerical) |
| Target | `risk_label` — `Low` / `Medium` / `High` |
| Missing values | 0 |
| Duplicate rows | 0 |
| Class balance | Medium 46.7% · Low 35.7% · High 17.6% |

**Features used by the model:** `crop`, `disease`, `growth_stage`, `day_of_year`, `avg_temp_c`, `avg_humidity_pct`, `rainfall_mm`, `leaf_wetness_hours`, `wind_speed_kmph`, `soil_moisture_pct`, `prior_regional_incidence_pct`.

## 🤖 Model

Three foundational classifiers were trained and compared: **Logistic Regression**, **Decision Tree**, and **K-Nearest Neighbors**. All categorical features are one-hot encoded and all numerical features are standard-scaled inside a single `scikit-learn` `Pipeline`, so the deployed `.pkl` file handles preprocessing and prediction together.

**Deployed model:** `KNN` — selected by highest macro F1-score on the held-out test set.

## ⚠️ Limitations

- **Dataset provenance** needs to be confirmed and credited (see [Dataset](#-dataset) above).
- `growth_stage` is a **deterministic function of `day_of_year`** (bucketed into Seedling / Vegetative / Flowering / Maturity), not an independently measured field — it adds a categorical view of the same signal rather than new information.
- ROC-AUC was not computed (optional for this multi-class setup per the project brief); only Accuracy, Precision, Recall, F1, and the confusion matrix were used.
- This is an **educational prototype**. Predictions must not be used as a substitute for professional agronomic diagnosis.
- The model was trained with `scikit-learn 1.9.1`; pin the same version (see `requirements.txt`) to avoid load errors on older installs.
